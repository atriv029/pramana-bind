We use a new network for performing feature extraction. Our new network is a hybrid approach between the network used in YOLOv2, Darknet-19, and that newfangled residual network stuff. Our network uses successive 3\times 3 and 1\times 1 convolutional layers but now has some shortcut connections as well and is significantly larger.
